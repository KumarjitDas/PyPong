# PyPong

PyPong is a simple and classic Pong game built with Python and Kivy, designed to bring back the retro gaming experience
with a modern touch. This project serves as both a fun game and a practical implementation of game development concepts
using the Kivy framework.

---

## Features

- Single-player mode with AI opponent
- Smooth animations and real-time collision detection
- Customizable game speed and paddle sensitivity
- Scoring system with win detection
- Responsive window resizing

---

## Requirements

To build and run PyPong, the following dependencies are required:

- Python 3.7+
- Kivy 2.1.0+

You can install the dependencies using the following command:

```
pip install -r requirements.txt
```

The `requirements.txt` file should include:

```
Kivy==2.1.0
```

---

## Building and Running

To build PyPong, simply navigate to the root directory and run:

```
python main.py
```

Ensure that you are in the root directory where `main.py` is located. To exit the game, press `Esc` during gameplay.

---

## Game Controls

- **W / S Keys** - Move left paddle up/down
- **Up / Down Arrow Keys** - Move right paddle up/down
- **Esc** - Quit the game
